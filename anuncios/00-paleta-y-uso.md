# Paleta Mesa Serena — anuncios y web

Usar estos colores en Instagram, WhatsApp y la landing. No inventar neón ni “fit green”.

| Nombre | Hex | Uso |
|---|---|---|
| Bosque | `#1B3A2F` | Fondos, portada, botones |
| Bosque profundo | `#12261F` | Texto sobre crema, footer |
| Crema | `#F6F0E4` | Fondo de anuncios y web |
| Papel | `#FFFBF4` | Tarjetas |
| Terracota | `#C45C3A` | Precio, CTA, énfasis |
| Terracota oscura | `#9A3F26` | Hover del botón |
| Oro | `#C4A46A` | Filetes, sellos |
| Sage | `#5C7A6A` | Bolsillo diario, detalles |
| Tinta | `#1A1A16` | Títulos |

**Tipografía de anuncios**
- Título: serif de recetario (Fraunces / Libre Baskerville)
- Cuerpo y precio: sans limpia (Outfit / DM Sans)

**Formatos**
- Feed / anuncio imagen: 1080 × 1350 (4:5)
- Historia / Reel cover: 1080 × 1920 (9:16) — recortar las mismas piezas
- Video: 9:16 vertical, 15–30 s

**Regla de texto en imagen**
Poco texto. Un hook. Un sello. Un precio. El resto va en el copy del anuncio, no encima de la foto.
